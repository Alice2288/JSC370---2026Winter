What this project is about

This project asks a simple question: can you predict how audiences will rate a movie just from its public metadata? Things like runtime, genre, release year, language, and a couple of engagement signals (vote count, popularity).

My midterm did exploratory analysis on 148 films from The Movie Database (TMDb) and found that no single variable explains ratings well on its own. Popularity barely correlates with rating. Budget and revenue track each other but not rating. Genres pull medians around a bit, but the spread within each genre is huge. So if no individual variable does the job, can a model that uses all of them at once?

For the final I scaled the dataset up to about 1,500 films and ran two prediction tasks:

  • Regression. Predict the continuous TMDb vote_average from movie metadata.
  • Classification. Predict whether a film is high-rated (rating at least 7.0).

Three models for each task: a linear baseline, Random Forest, and XGBoost. Standard 60/20/20 train/validation/test split.

Data and methods at a glance

Source TMDb REST API. I used /discover/movie across five sort strategies (recent popular, classic popular, most-voted, top-rated, highest grossing) and then /movie/{id} for the per-film details.

Sample About 1,500 unique films after deduplication and a vote_count ≥ 30 noise filter.

Features Engagement (log vote count and log popularity), production characteristics (runtime, release year, budget and revenue when reported, country, language, company count), plus 18 binary genre indicators.

Models Linear/Logistic regression as baselines, Random Forest, XGBoost. random_state = 370 so anyone running the code gets the same numbers.

Metrics Regression: R², RMSE, MAE. Classification: accuracy and ROC AUC.

Main findings

  • Both Random Forest and XGBoost beat the linear baseline by a clear margin on the test set. The two tree models are roughly tied: XGBoost is marginally ahead on RMSE and accuracy, Random Forest is marginally ahead on ROC AUC.
  • The strongest predictors are genre indicators (genre_animation, genre_drama, genre_music) together with is_english and release_year. The model leans on the systematic rating differences across genres and languages more than on any single engagement signal.
  • Engagement features (log_vote_count, log_popularity) still contribute, but they sit in the middle of the importance ranking rather than at the top — a different story from the smaller 148-film midterm sample, where engagement looked dominant.
  • The high-rating classifier (rating ≥ 7.0) reaches ROC AUC near 0.87, with Random Forest and XGBoost essentially tied.

How to reproduce everything

From the final-project/ directory:

# 1. install dependencies
pip install -r requirements.txt

# 2. collect movie metadata (about 5 minutes, polite rate-limited)
quarto render collect_data.qmd

# 3. run the analysis end-to-end (cleans, models, builds all figures)
quarto render analysis.qmd

# 4. (optional) rebuild the PDF
quarto render report/report.qmd

The data/ folder holds the saved CSV. figures/ has the static PNGs the report uses. docs/ has this website plus the standalone interactive plotly HTML files.
